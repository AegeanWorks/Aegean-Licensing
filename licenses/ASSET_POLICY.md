# AegeanWorks Asset Separation & Licensing Policy

**Version 1.0 — October 2026**  
**Contact**: `aegean-licensing@proton.me`

This policy governs the categorization, licensing, and commercial use of materials hosted within AegeanWorks repositories, delineating software source code from creative and domain assets.

---

### 1. Scope & Categorization

To maintain legal certainty and prevent ambiguity between licensed code and proprietary assets, files across AegeanWorks repositories fall into four distinct categories:

| Category | Typical File Types | Default Public License | Commercial Track Option |
|---|---|---|---|
| **Software Source Code** | `.py`, `.c`, `.rs`, `.js`, `.ts`, `.html`, build scripts | Aegean License 1.0 (AL-1.0), personal use only | Aegean Commercial License (ACL-1.0) |
| **Documentation & Guides** | `README.md`, `docs/`, inline docstrings | Aegean License 1.0 (AL-1.0), personal use only | Aegean Commercial License (ACL-1.0) |
| **Domain & Creative Assets** | 3D models, textures, audio, clinical templates, proprietary datasets | Non-Commercial / Personal Use Only | Dedicated Commercial Asset Grant |
| **Trademarks & Branding** | Logos, icon badges, project names, wordmarks | All Rights Reserved | Written Consent Only |

### 2. Category Details

#### 2.1 Software Source Code
All program code, unit tests, algorithms, and automated scripts are licensed under the **Aegean License 1.0 (AL-1.0)** by default: an individual may run, inspect, and modify the code for private, non-commercial use. Any commercial or organizational use requires an **ACL-1.0** license. Versions released under GNU AGPL-3.0 before a project moved to AL-1.0 keep that license.

#### 2.2 Documentation & Specifications
Repository documentation, code explanations, architectural diagrams, and usage tutorials are Covered Material under the **Aegean License 1.0 (AL-1.0)**: free to read and study for personal use, but republishing, translating or adapting them, commercially or not, needs written permission. Documentation already released under CC-BY-4.0 keeps that license for those versions.

#### 2.3 Domain & Creative Assets
Specialized non-code assets included in specific repositories—such as medical clinic documentation templates (`NeurologyClinicTemplates-TR`), game 3D models and audio (`voidfarer`, `aldervale`), or pre-trained model weights—are protected proprietary creative works. They are provided in public repositories solely for evaluation, personal study, or non-commercial testing. Use in revenue-generating commercial services, clinics, or commercial games requires explicit licensing through `aegean-licensing@proton.me`.
