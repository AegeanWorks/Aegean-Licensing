# AegeanWorks Asset Separation & Licensing Policy

**Version 1.0 — October 2026**  
**Contact**: `aegean-licensing@proton.me`

This policy governs the categorization, licensing, and commercial use of materials hosted within AegeanWorks repositories, delineating software source code from creative and domain assets.

---

### 1. Scope & Categorization

To maintain legal certainty and prevent ambiguity between copyleft code and proprietary assets, files across AegeanWorks repositories fall into four distinct categories:

| Category | Typical File Types | Default Public License | Commercial Track Option |
|---|---|---|---|
| **Software Source Code** | `.py`, `.c`, `.rs`, `.js`, `.ts`, `.html`, build scripts | GNU AGPL-3.0-or-later | Aegean-E Commercial License (AECL-1.0) |
| **Documentation & Guides** | `README.md`, `docs/`, inline docstrings | CC-BY-4.0 / AGPL-compatible | CC-BY-4.0 / Permissive Reference |
| **Domain & Creative Assets** | 3D models, textures, audio, clinical templates, proprietary datasets | Non-Commercial / Personal Use Only | Dedicated Commercial Asset Grant |
| **Trademarks & Branding** | Logos, icon badges, project names, wordmarks | All Rights Reserved | Written Consent Only |

### 2. Category Details

#### 2.1 Software Source Code
All program code, unit tests, algorithms, and automated scripts are licensed under the **GNU Affero General Public License v3.0 (AGPL-3.0)** by default. Anyone may run, inspect, and modify the code. Modified versions shared or offered over a network must provide complete corresponding source under Section 13. Businesses requiring closed-source operations or waiver of copyleft obligations obtain an **AECL-1.0** license.

#### 2.2 Documentation & Specifications
Repository documentation, code explanations, architectural diagrams, and usage tutorials are open for community reference and learning under Creative Commons Attribution 4.0 International (CC-BY-4.0) or AGPL-3.0 compatible terms.

#### 2.3 Domain & Creative Assets
Specialized non-code assets included in specific repositories—such as medical clinic documentation templates (`NeurologyClinicTemplates-TR`), game 3D models and audio (`voidfarer`, `aldervale`), or pre-trained model weights—are protected proprietary creative works. They are provided in public repositories solely for evaluation, personal study, or non-commercial testing. Use in revenue-generating commercial services, clinics, or commercial games requires explicit licensing through `aegean-licensing@proton.me`.

#### 2.4 Trademarks and Project Identity
The names "AegeanWorks", "AIKit", and all associated logos, visual marks, and badge designs are proprietary marks of AegeanWorks. Neither AGPL-3.0 nor AECL-1.0 grants trademark usage rights. You may not use AegeanWorks marks to imply endorsement or origin of third-party derived products without explicit written authorization.
